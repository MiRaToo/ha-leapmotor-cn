# ha-leapmotor-cn

**零跑汽车 Home Assistant 集成** · **v0.2.1**

**非官方的集成** —— **在 Home Assistant 里使用你的零跑汽车**：远程车控、实时车况、行程记录与能耗统计，
全部以 **HA 原生实体**呈现，并自带一套控车相关的**前端卡片**。

接入走**零跑云端的 HTTP 接口**
在 HA 里输入手机号 + 短信验证码即可完成登录。

## 功能

| 分类 | 内容 |
|---|---|
| **车辆控制** | 车门锁 · 后备箱 · 遮阳帘 · 车窗四档（全开 / 微开 / 半开 / 关）· 寻车鸣笛 · 空调（含温度设定）· 座椅加热与通风（0~3 档，多排座车型含二排·三排¹）· 方向盘加热 · 后视镜加热 · 电池预热 · 健康充电 · 预约充电（含充电上限与起止时间） |
| **车辆状态** | 位置 · 电量 · 续航 · 充电状态 · 车辆状态 · 状态更新时间 · 车内温度 · 四轮胎压 · 增程¹（剩余燃油 / 燃油续航 / 油电总续航 / 油耗） |
| **里程能耗** | 总里程 · 近 7 天里程 · 近 7 天能耗 · 百公里能耗 · 能耗排名 · 交付天数 —— 逐日耗电采用**官方云端口径**，获取缺失时自动用本机自记兜底 |
| **行程记录** | 每趟开车的**轨迹 · 起止时间 · 里程 · 耗电 · 百公里能耗**（本机采样记录，行驶中 6 秒一帧）· 今日 / 7 天 / 30 天统计 |
| **照片与诊断** | 驻车照片（泊车后自动补齐）· 最近指令回执 · 原始指令（cmdId）· 会话状态 · 刷新车况 |
| **界面（自带卡片）** | **控制卡** `custom:leapmotor-control`：App 风格（车况 / 空调 / 座椅 / 充电 / 燃油 / 胎压；车模按你的车型显示官方外观图²）· **地图卡** `custom:leapmotor-map`：高德底图，在卡片上拖圆创建地理围栏，围栏随地图拖动实时同步 · **行程卡** `custom:leapmotor-trips`：每段一张带缩略图的小卡 + 详情页 · **里程/耗电卡** `custom:leapmotor-energy`：逐日折线，周/月切换，三线可叠显 · **上周能耗卡** `custom:leapmotor-lastweek`：驱动 / 空调 / 其它拆分 —— **五张卡的界面预览见 [docs/showcase.md](docs/showcase.md)** |

¹ 按车端实际上报的能力位 / 信号自动出现，纯电车型不会多出这些实体。
² 车模图只包含C10 / C01 / T03 / B10 / C11 / C16 ，目前无实际功能，其余车型自动回退内置简笔画。

配套特性：

- **自适应轮询**：行驶中 6 秒一帧、停车 60 秒（可调低到 20 秒）；
  解锁 / 上电自动提速，短停再出发继续快档
- **会话自动续期**：账号 token 与车端 token 均自动续期，正常使用不需要重复收短信；
  签名轮换时自动换 token 重试，不会误报"会话失效"
- **数据本地化**：行程与逐日能耗都保存在本地 HA（`.storage/`）；官方逐日能耗拉一次即缓存，
  日常零额外请求；命中云端限流会自动冷却退避
- **坐标自动换算**：对外发布 WGS-84 坐标，可直接用于 HA 地图、区域与手机定位口径
- **失败可见**：云端未受理的指令会直接报错提示，不会出现"界面显示成功、车没动"
- **按权限门控**：读取车辆授权清单（`rightList`），没有授权的功能不显示

## ⚠️ 请用一个单独的子账号接入

零跑云同一账号只允许一个活跃登录。本项目需要持续轮询，**用主账号会导致你的手机
App 被顶下线**。正确做法：

1. 注册一个**子账号**（备用号、家人号均可）
2. 主账号在官方 App 里打开 `我的 → 我的车辆 → 车辆共享`，邀请该子账号
3. 子账号在官方 App 里接受邀请
4. 用**子账号**接入本集成

这样主账号完全不受影响，日常手机控车照常；子账号的权限由主账号掌握，随时可以收回。

> **不要用主账号登录本项目。**

## 安装与使用

1. 把 `custom_components/leapmotor/` 复制到 HA 的 `config/custom_components/`
   （HACS 用户可把本仓库添加为自定义仓库后直接安装）
2. **重启 Home Assistant**
3. **设置 → 设备与服务 → 添加集成 → 搜「零跑」** → 选「零跑汽车」
4. 填**子账号**手机号 → 收到短信 → 填验证码 → 完成
5. 根据需要在配置中配置车辆操作密码等

装好后会得到一个车辆设备与一组实体，设备页里按「车身 → 充电 → 舒适 → 按钮 → 车况 →
里程能耗 → 行程 → 诊断」排列：

| 段 | 实体 |
|---|---|
| 车身 | 车门锁 / 后备箱 / 遮阳帘 / 方向盘加热 / 后视镜加热 |
| 充电 | 健康充电 / 预约充电 / 充电上限 / 预约充电-开始 / 预约充电-结束 |
| 舒适 | 空调 / 主驾·副驾座椅加热 / 主驾·副驾座椅通风 / 车内温度（多排座车型另带二排·三排实体） |
| 按钮 | 寻车鸣笛 / 车窗-全开 / 微开 / 半开 / 关 / 电池预热-开 / 关 / 刷新车况 |
| 车况 | 电量 / 续航 / 充电状态 / 车辆状态 / 状态更新时间 / 四轮胎压 / 位置 |
| 里程能耗 | 总里程 / 近 7 天里程 / 近 7 天能耗 / 百公里能耗 / 能耗排名 / 交付天数 |
| 行程 | 最近行程 / 行程轨迹 / 行程统计 |
| 诊断 | 驻车照片（含地址）/ 充电配置 / 最近指令回执 / 会话状态 / 原始指令 |

操作密码、轮询间隔与**电池可用容量**（用于行程耗电折算；默认 67.0 kWh = C10 纯电 RWD 的
**可用**容量，其它车型请按自己车辆的实际情况填写可用容量）都在该集成条目的 **配置** 里修改。
部署方式见 [docs/DEPLOY.md](docs/DEPLOY.md)，使用说明与常见问题见 [docs/SETUP.md](docs/SETUP.md)，
仪表盘与卡片用法见 [docs/dashboard.md](docs/dashboard.md)。

## 项目结构

```
ha-leapmotor-cn/
├── custom_components/leapmotor/   ★ HA 自定义集成(用户实际安装的部分)
```

## 开发状态

### 已实现

- **认证与协议**：手机号 + 短信验证码登录；账号 token 与车端 JWT 均自动续期；
  请求签名与密钥派生均为纯 Python 实现
- **车辆控制**：门锁 / 后备箱 / 遮阳帘 / 车窗四档 / 寻车 / 空调 / 座椅加热通风（含多排座¹）/
  方向盘与后视镜加热 / 电池预热 / 健康充电 / 预约充电
- **车辆状态**：90 余项车端信号（位置 / 电量 / 续航 / 胎压 / 门窗 / 充电 / 空调 …）
- **行程记录**：挡位判行程 + 停车确认；自采样轨迹（默认行驶 6 秒一帧）；
  里程取总里程差分、耗电取 ΔSOC × 可用容量；失联时按里程跳变补记（标注"无轨迹"，
  带毛刺与均速护栏）；三档轮询（行驶 6s / 停车 60s 可调 / 出发提速 + 短停快档）
- **里程与能耗**：逐日耗电取自**云端拆分**（驱动 / 空调 / 其它，0.1 kWh；已完结的
  日子缓存后不再重拉），官方缺数用本机自记兜底；支持周 / 月视图与统计
- **界面**：五张自带卡片（见上表）+ 按车型的官方车模图 + HomeKit 桥 YAML 生成器

### 验证状态（如实说明）

| 项目 | 状态 |
|---|---|
| **C10 纯电（开发用车）** | ✅ 全功能真车实测：车控 / 车况 / 行程 / 能耗 / 五张卡片 |
| 控制卡与四张卡片 | ✅ 离线渲染回归（331 / 72 / 47 / 21 断言）+ 真车日常使用并持续打磨 |
| **C16 多排座 / 增程（REEV）** | 🧪 **暂无真车样本**：按官方报文格式实现（并与海外开源项目交叉印证） |
| B10 / C11 / C01 / T03 等 | 🟡 协议同源；车模图已适配；车况 / 控车待真车逐项验证 |

### 尚未支持 / 已知限制

- **多车型信号表**：以 C10 实测为准，其它车型个别信号可能有缺，发现缺漏欢迎反馈
- **天窗**：本车无此配置，未实现
- **预约空调 / 预约电池预热**（cmdId 171 / 161）：请求体结构未知
- **哨兵模式**：指令码已查明，但其所需要的权限**无法由主账号授予子账号**
  （云端恒回"无此权限"），因此本集成不提供该实体
- **空调快捷模式**（极速降温 / 升温 / 除味 / 除霜）
