# Beta 更新日志

> 这份日志面向**测试用户**:只写"改了什么、修了什么、还有什么已知问题",不写实现细节。
> 稳定版(`main` 分支)不含这里的功能。

---

## 2026-10-03

### 修复
- **行程补记增强护栏**:
  - 单帧总里程**毛刺**(信号异常/云端串帧, 一次跳上千公里)不再入账, 也不会污染后续对比;
  - 补记行程的**时长不可信时留空显示 "—"**(里程/耗电照记)——
    以前"3 公里开了 40 小时"这种观测区间会被当成行程时长写出来;
  - **HA 重启后不再误判**: 重启时云端常把同一帧再回一遍, 现在能认出它是旧数据,
    补记的起止区间不会缩水或漂移到"重启时刻"。
- **充电 / 座椅与加热两张并排卡**不再因"摘要有无"而高低不一、标题错位(窄屏下也齐平)。
- 行程卡里"补记段时长为空"时不再输出 `≈ —`(只显示 `—`)。

## 2026-10-02

### 新增
- **行程记录**:每趟开车的轨迹 / 起止时间 / 里程 / 耗电 / 百公里能耗;配套「行程浏览」卡片
  (`custom:leapmotor-trips`)与「最近行程 / 行程轨迹 / 行程统计」三个实体。
- **车辆控制卡** `custom:leapmotor-control`(App 风格):
  - 顶部大续航 + 电量条 + 锁状态;增程车显示「⚡纯电 / ⛽燃油」两个续航胶囊
  - 四圆钮:解锁·上锁 / 后备箱 / 车窗(四档气泡)/ 遮阳帘
  - 车模 + 胎压开关(四轮按方位标注)、空调卡(三个模式图标)、位置卡(驻车照片作背景)
  - **座舱俯视控制**:方向盘、左右后视镜、前排/二排/三排座椅按真实位置排布;
    加热档位用**红色风扇**、通风用**蓝色风扇**、关闭为**灰色**(档位越高亮起的扇叶越多)
  - 充电 / 座椅与加热 / 燃油 / 行程 四个块默认收起,点标题行展开(会记住你的选择)
- **C16 多排座**:二排左/右座椅加热·通风、三排左/右座椅加热(命令与官方 App 一致)。
- **增程车型燃油数据**:剩余燃油 %(含升数)、燃油续航、油电总续航、油耗。

### 修复
- **驻车照片更"及时"也更"省"**: 停车后的"等上传"窗口从 2 分钟延长到 **15 分钟**,
  但重试节奏改成**递增退避**(15s→30s→60s→120s→300s)—— 照片通常很快到, 拿到了就立即停;
  车端迟迟不传时越试越慢, 不再白问。照片实体上也多了 `upload_time` 与 `pending`(待补)两个属性。
- **重数据请求更快**: 里程/能耗/配置原来串行发 3~4 个请求(还有一个重复请求), 现在**并发**、
  且去掉了重复的那个(约 0.85s → ~0.3s);它们仍保持 600 秒的独立节奏, 不跟着高频轮询跑。
- **缩略图里的轨迹与底图不再"错位"**(之前缩略图把轨迹按 k 倍缩放、却忘了把瓦片一起缩放,
  两者不同尺度 —— 表现就是"缩略图的路线和大图不一样";实测 k 可达 1.6,即偏 60%)。
  顺带修了窄屏下**跨天行程的时间段被省略号截断**(改成换行显示)。
- **轮询提速修好了**(之前"行驶中 6 秒一帧"其实从未生效: 间隔在最后一步被悄悄钳到最小 60 秒,
  导致行程点稀疏、短途行程大量变成"补记")。
- **新增两个可调项**:①「轮询间隔(停车)」下限放宽到 **20 秒**(默认仍 60);
  ②「**短停快档**」(默认 300 秒, 0=关闭) —— 一趟行程结束后继续用快档, 抓住"短停再出发"。
- **充电状态误报"行驶中充电中"**:判据改为与官方 App 一致(只有车端状态码 = 充电中才算),
  行驶/能量回收时不再误报。
- **控制卡图标缺失**:解锁、后备箱原来用的是两个**不存在的图标名**(显示为空白)、车窗用了
  卷帘图标;已全部换成正确的官方图标,并逐个校验过。
- **车窗四档气泡位置偏移**:气泡现在精确贴在车窗圆钮下方,不再遮挡其它卡片。
- 行程记录的补充说明:车端偶尔"不回新数据"时,某趟行程可能**只有里程没有轨迹**(会标注
  「补记」),里程与耗电仍然准确;这是数据源限制,不是 bug。
- HA 重启被集成拖慢(首轮一次性发起太多请求)已优化为"首轮只拉车况"。

### 其它 / 已知问题
- **后排座椅与增程燃油这两块没有真车样本**(按官方 App 的报文格式实现),
  这正是需要 C16 / 增程车主帮忙验证的部分 —— 见 [测试表](test-c16-reev.md)。
- 驻车照片是**泊车那一刻**拍的,拍完异步上传:刚停下车时可能还是上一张,集成会在 15 分钟内
  自动重试(节奏递增),仍没有会标「待补」。
- 轨迹点的疏密取决于轮询节奏(行驶中设计值 6 秒一帧,与官方 App 前台一致);
  若 HA 主机负载高,实际会变稀,轨迹会有"抄近道"的直线段。
- 哨兵模式不提供:它的权限无法授予子账号(云端恒回"无此权限")。
- 空调**没有**后排分区控制(官方 App 里也没有,后排是出风口)。
