# Beta 更新日志

> 这份日志面向**测试用户**:只写"改了什么、修了什么、还有什么已知问题",不写实现细节。
> 稳定版(`main` 分支)不含这里的功能。

---

## 2026-10-02

### 新增
- **行程记录**:每趟开车的轨迹 / 起止时间 / 里程 / 耗电 / 百公里能耗;配套「行程浏览」卡片
  (`custom:leapmotor-trips`)与「最近行程 / 行程轨迹 / 行程统计」三个实体。
- **车辆控制卡** `custom:leapmotor-control`(App 风格):
  - 顶部大续航 + 电量条 + 锁状态;增程车显示「⚡纯电 / ⛽燃油」两个续航胶囊
  - 四圆钮:解锁·上锁 / 后备箱 / 车窗(四档气泡)/ 遮阳帘
  - 车模 + 胎压开关(四轮按方位标注)、空调卡(三个模式图标)、位置卡(驻车照片作背景)
  - **座舱俯视控制**:方向盘、左右后视镜、前排/二排/三排座椅按真实位置排布;
    加热档位用**红色风扇**、通风用**蓝色风扇**、关闭为**灰色**(档位越高亮起的扇叶越多)
  - 充电 / 座椅与加热 / 燃油 / 行程 四个块默认收起,点标题行展开(会记住你的选择)
- **C16 多排座**:二排左/右座椅加热·通风、三排左/右座椅加热(命令与官方 App 一致)。
- **增程车型燃油数据**:剩余燃油 %(含升数)、燃油续航、油电总续航、油耗。

### 修复
- **充电状态误报"行驶中充电中"**:判据改为与官方 App 一致(只有车端状态码 = 充电中才算),
  行驶/能量回收时不再误报。
- **控制卡图标缺失**:解锁、后备箱原来用的是两个**不存在的图标名**(显示为空白)、车窗用了
  卷帘图标;已全部换成正确的官方图标,并逐个校验过。
- **车窗四档气泡位置偏移**:气泡现在精确贴在车窗圆钮下方,不再遮挡其它卡片。
- 行程记录的补充说明:车端偶尔"不回新数据"时,某趟行程可能**只有里程没有轨迹**(会标注
  「补记」),里程与耗电仍然准确;这是数据源限制,不是 bug。
- HA 重启被集成拖慢(首轮一次性发起太多请求)已优化为"首轮只拉车况"。

### 其它 / 已知问题
- **后排座椅与增程燃油这两块没有真车样本**(依据官方 App 的数据契约实现),
  这正是需要 C16 / 增程车主帮忙验证的部分 —— 见 [测试表](test-c16-reev.md)。
- 驻车照片是**泊车那一刻**拍的,拍完异步上传:刚停下车时可能还是上一张,集成会在 2 分钟内
  自动重试,仍没有会标「待补」。
- 轨迹点的疏密取决于轮询节奏(行驶中设计值 6 秒一帧,与官方 App 前台一致);
  若 HA 主机负载高,实际会变稀,轨迹会有"抄近道"的直线段。
- 哨兵模式不提供:它的权限无法授予子账号(云端恒回"无此权限")。
- 空调**没有**后排分区控制(官方 App 里也没有,后排是出风口)。
