# 预约与车机工具

「充电」「设置」采用全页遮罩弹窗，正文独立滚动，右上角可随时关闭，也支持 Esc。新增工具位于控车卡弹窗内，需要当前 HA 用户为管理员；多车按当前卡片选中的车辆实体解析，不会默认发送到第一辆车。

车窗、锁、后备箱、遮阳帘、空调、加热与座椅命令受理后，集成会短时只读复查车况。命令后的新鲜采样吻合目标时立即结束等待；三分钟内仍无匹配回报则显示「车端未确认」并恢复车端实际信号。不会重发控车命令，后续匹配的真实回报会清除未确认提示。缺少关闭信号时保留未知。

## 充电与电池预热预约

打开「充电」，已有的预约开关、充电上限和起止时间继续使用原实体。新增：

- 预约充电重复：周日到周六可独立选择；全部不选为仅下一次。
- 「到停止时间未达到充电上限，将继续充电」开关。
- 预约电池预热开关、开始时间及周日到周六的重复；车辆自动结束，没有结束时间输入。

预约开关下发受理后显示「待车端确认」，短暂保留新值，并在三分钟内以退避间隔只读复查计划，回报一致后解除；未确认超过三分钟则恢复云端回报。连续修改其它计划项会保留刚受理的修改，避免被延迟配置覆盖。界面仅保留一处预约电池预热开关。预热开关即时提交，失败恢复原值；启用时才显示开始时间与重复日期，后续修改需点右侧保存。预约充电关闭时收起起止时间、重复与续充。

重复与续充选择后点「保存充电重复与续充」；预热选择后点「保存预热预约」。没有读到当前充电计划时不会以默认上限、默认起止时间覆盖。预热保存前重新读取全部预约，保留其它记录；读取失败或格式未知时显示暂不可用，并保留原计划。时间按照 HA 时区，单次开始时刻已过去时安排下一次。

## 发送目的地

「设置 → 发送目的地」可选择 HA 区域，或填写名称、地址与经纬度。HA 区域使用 WGS-84；高德和腾讯坐标使用 GCJ-02，手动输入时需选对坐标类型。集成根据车端能力位 39 决定是否转换为 WGS-84 再发送。

点击「发送到车机」后仅在云端受理时显示待车端确认；接收和导航效果以车辆实际结果为准。此功能不会自动开始驾驶、创建路线记录或改变 HA 区域。

可在控车卡「设置 → 高德 Web 服务 Key」展开设置，或在「设置 → 设备与服务 → 零跑 → 配置」填写。卡片中的设置默认收起，摘要显示配置状态。申请类型为 Web 服务 API，填写 32 位 Key；不是 JavaScript API Key，不需要在卡片填入 JS 安全密钥。Key 只保存在 HA 配置中，卡片仅获知是否已配置。留空后保存可关闭，现有地图不依赖它。

配置后「发送目的地」可按地点名称与城市手动搜索，选择结果会填入名称、地址、POI ID 与 GCJ-02 坐标，仍需点击发送。查询由 HA 访问高德官方地点搜索接口，不在浏览器加载第三方脚本，不随车辆轮询或输入自动查询；配额、IP 白名单与权限以高德账号配置为准。接口依据[高德 Web 服务地点搜索文档](https://developer.amap.com/api/webservice/guide/api/search/)。

## 上传全景壁纸

「设置 → 上传全景壁纸」先选择文件，查看预览后点击「上传到车机」。只支持 JPEG、PNG，图片宽须大于 1920、高须大于 960，最大 4096×2048，比例为 2:1，文件不超过 2 MiB。尺寸与文件格式会在浏览器和 HA 服务端分别检查，不会根据文件名判断图片内容，也不会自动裁剪或拉伸。

上传使用 App 的全景壁纸类型 3；部分车型或车机版本可能不支持，云端拒绝时显示错误。图片仅在提交时发送到零跑的上传接口，不保存到本集成的账本中。HA 接收文件使用有限大小的消息，超过限制应先自行压缩图片。

新功能依据官方 App 的载荷结构实现，并经过离线测试；不代表已在每个车型实车验证。不要将「云端已受理」理解为「车端已完成」。


## 本机车衣与 3D 显示

设置 → 车衣 → 上传与预览，通过文件夹式选择器切换左侧、右侧、车顶、车头和车尾，每个面可以独立上传图片并调整水平/垂直位置、大小、旋转与透明度。多个面的图案同时生效，切换面保留当前草稿。支持不超过 8 MiB 的 PNG/JPEG/WebP，工具会缩小图片以控制显存和本机存储占用。确定保存，返回恢复原设置；可清除当前面或全部车衣，再确定保存。旧版单面车衣会自动读入对应面。

图片保存在当前浏览器、按车辆区分，不上传 HA 或零跑服务器。该方式投影到车漆区域，不修改玻璃与饰条；复杂曲面、开启的车门等部件可能有投影变形。

行驶且车速有效时使用查看器的车轮与地面运动，限制为 20 fps；停车、隐藏页面、车模滚出可视区域或系统减少动态时停止持续运动。续航旁显示车速；明确充电时显示绿色功率和已知枪型 AC/DC。缺少信号显示未知。

点击胎压用短时相机过渡切到俯视，临时锁定旋转；舞台大小保持不变，读数按实际轮位投影并移到轮胎两侧。关闭时过渡恢复原视角，系统要求减少动态时直接切换。不同素材未提供轮位时不伪造轮位。行驶效果只表达运动，动画速度低于实际车速，数字仍显示真实车速。
