# 零跑汽车 → Home Assistant 接入指南

> 把零跑(Leapmotor)汽车接进 HA:车况(GPS/电量/续航/胎压/门锁/充电/空调)+ 远程控制。
> **不需要模拟器、不需要 root** —— 在 HA 里输手机号 + 短信验证码即可。
> 协议细节见 [PROTOCOL.md](PROTOCOL.md),开发者见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## ⚠️ 第 0 步(必做):准备一个**子账号**

零跑云**单账号单会话**:同一个账号在别处登录,会把手机上的官方 App 顶下线。

| | 主账号 | 子账号 |
|---|---|---|
| 日常手机控车 | ✅ 不受影响 | — |
| 本项目(HA)接入 | — | ✅ 被顶下线也无所谓 |
| 权限 | 车主,可管理共享 | 由主账号授予,**随时可收回** |

做法:

1. 用另一个手机号注册零跑账号(家人的号、备用号都行)
2. 主账号打开官方 App:`我的 → 我的车辆 → 车辆共享 / 授权用车 → 输入子账号手机号 → 发送邀请`
3. 子账号登录官方 App,在消息里接受共享
4. 本项目一律用**子账号手机号**登录

> 车始终在你的控制之下:随时可在 `车辆共享` 里删掉授权,子账号立刻失效。

## 1. 安装(自定义集成,推荐)

把 `custom_components/leapmotor/` 放到 HA 的 `config/custom_components/` 下:

* **Samba**:把 `leapmotor` 整个目录拖进 `\\<HA地址>\config\custom_components\`
* **SSH**:`scp -r custom_components/leapmotor root@<HA>:/config/custom_components/`
* **HACS**:把本仓库加为自定义仓库(类型选 Integration)后安装

然后 **重启 HA** → 设置 → 设备与服务 → **添加集成** → 搜「零跑」。

> 不需要 MQTT broker、不需要附加组件、不需要额外前端资源 ——
> 集成**自带一张高德底图地图卡**(`custom:leapmotor-map`),装上即可用,见 [dashboard.md](dashboard.md)。

## 2. 首次登录

1. 添加集成 → 填**子账号手机号** → 提交后会收到短信验证码
2. 填 6 位验证码(5 分钟内有效)→ 自动完成账号登录 + 车端交换 + 密钥派生
3. 之后在集成的「配置」里填**车辆操作密码**(车机上/App 里设的 4 位数字)—— 解锁等敏感指令需要它

### 会话寿命(基本不用管)

* 账号 token 只有约 **6 小时**,但集成会**自动免密续期**(车端 token 每次到期前顺手刷新账号 token,
  实测 `code=200`,refresh token 不轮换)—— **正常情况下不需要你再收短信**
* 只有一种情况需要手动介入:**refresh token 本身失效**(例如在别处重新登录、或在官方 App 里
  退出登录)。这时集成会:
  1. 提前 **30 分钟**发一条 HA 通知
  2. 失效后**车端 token 仍有效时继续工作**(约多撑 2 小时),同时再发一条通知
  3. 彻底失效时集成会被标成需要处理 → 设置 → 设备与服务 → 零跑 → **重新认证** → 收短信、填验证码
* **不需要删除集成重装**;验证码超时了也没关系,认证页面里勾选「重新发送验证码」再提交一次
* 诊断传感器「会话状态」随时显示当前状态(正常 / 需要重新登录 / 本轮刷新失败的原因)

## 3. 你会得到什么

| 类型 | 实体 |
|---|---|
| 定位 | **车辆位置**(`device_tracker`,直接上 HA 地图)+ 自带高德地图卡 |
| 车况 | 电量、续航、四轮胎压、车内温度、车辆状态(行驶/驻车)、充电状态、**状态更新时间** |
| 里程能耗 | 总里程、近 7 天里程/能耗、百公里能耗、能耗排名、交付天数 |
| 控制 | 车门锁(真实状态)、空调(开/关 + 温度)、座椅加热通风(主/副驾)、方向盘加热、后视镜加热、车窗(全开/微开/半开/关)、遮阳帘、后备箱、寻车鸣笛、电池预热 |
| 充电 | 健康充电开关、充电上限(50~100%)、预约充电开关 + 起止时间 |
| 诊断 | 会话状态、充电配置、驻车照片(地址 + 图片实体)、最近指令回执、原始指令(cmdId) |

## 4. 常见问题

**Q: 提示"账号下没有可用车辆"?**
子账号还没被共享车辆,或共享邀请没接受 —— 回到第 0 步。

**Q: 指令报"无此权限"(`code=40`)?**
该指令没有被授权给这个子账号。授权清单由主账号设定(车辆列表的 `rightList`),
**哨兵模式、空调快捷模式**等属于主账号也无法转授的功能,属正常现象。

**Q: 指令受理了但车没反应?**
① 操作密码不对(连错 3 次锁 5 分钟);② 车端条件不满足 —— 例如电池预热在电池温度
合适时会被车端拒绝执行;③ 车端状态上报有延迟,以 `状态更新时间` 为准。

**Q: 提示"环境被风控(1023)"?**
停手静默等待 30 分钟以上,期间不要重试 —— 继续请求会延长冷却。

**Q: 能在手机上重新认证吗?**
可以。HA 的 Companion App 里同样能打开集成页面完成认证。

## 5. 安全与合规

> ⚠️ 本项目为**个人开发**的非官方项目:需要你把账号会话与车辆操作密码存在 HA 里,
> 并会向零跑云下发真实车控指令,**风险由使用者自行承担**;零跑官方一旦调整接口,
> 部分功能可能失效。请勿用于商业或违法违规用途。完整条款见
> [README 的免责声明](../README.md#免责声明)。

* 只使用**你自己账号**在**你自己车**上的官方 App 行为,没有绕过、没有攻击任何服务
* token / 操作密码 / 会话文件都在 HA 本地,不会上传到任何第三方
* 建议用子账号:主账号留在手机上,项目出问题也不影响日常用车
* 车控指令会真实作用于车辆,请勿在行驶中或不确定的场景下远程操作(多数指令要求车辆驻车)
