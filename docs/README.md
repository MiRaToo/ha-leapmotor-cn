## 文档维护约定

公开文档保留当前使用方法、稳定技术结论和必要限制。开发日志、交接、实验记录、审核记录、发布工作流及改造方案使用 `PRIVATE-` 文件名前缀，由 `.gitignore` 统一忽略，只在本地维护。公开文档不链接这些内部文件。

Git 忽略规则不会自动移除已经跟踪的文件；将已有公开文档转为内部文档时，需要同时检查其 Git 跟踪状态。
