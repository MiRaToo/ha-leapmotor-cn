# 3D 车模问题：如何协助排查

本地真实素材已验证 C10 2026、B10 2025，以及 B05/Lafa5 2026 普通版与 Ultra 的完整模型加载。B05 接口车型名与资源名不同：普通版使用 Lafa5，Ultra 使用 Lafa5Ultra；装配检查、缓存复用和色表读取会按版型选择对应目录。其它车型仍需各自样本，本地模型加载通过也不能代替车主 HA 的安装状态或手机浏览器兼容验证。

## 先收集现有信息

1. 记录车型、年款、配置版本，以及官方 App 是否能显示并旋转 3D 车模。
2. 在车辆控制卡的「设置」中记录 3D 状态文字。
3. HA → 设置 → 设备与服务 → 零跑汽车 → 下载诊断。先发送这份文件即可，不必反复点下载。
4. 如果是能下载但画面空白，补充浏览器/手机系统版本，以及出错画面的截图。说明是否只有某个浏览器失败。

诊断中 `car3d.last_error_detail` 的响应形状可以区分：云端没有下发车型参数、只返回 2D 模式、包不是 ZIP、包下载不完整、模型目录不匹配。`modelType=2` 只说明这一次返回 2D 模式，成因仍需证据。

## 需要进一步取样时

稳定版集成已包含浅层与深度诊断动作。按下文调用 leapmotor.car3d_probe 即可生成样本；诊断动作只读取素材相关数据，不执行车控。

## 采集本车素材

需要协助核对 3D 模型、查看器或 2D 外观素材时，可将本车素材保存到 HA 的本机配置目录。此操作会复用当前集成会话，只读取素材接口。

在“开发者工具 → 动作”调用：

```yaml
action: leapmotor.collect_assets
data:
  include_h5: false
```

素材和清单写入 `/config/leapmotor-assets/<车型>_<年份>/`。`include_h5` 默认为 `false`；仅在排查查看器时设为 `true`。素材归零跑所有，仅保存在自己的 HA 中，不要将原始素材包公开或附在公开问题中。

## 深度探针

HA → 开发者工具 → 动作，调用一次：

```yaml
action: leapmotor.car3d_probe
data:
  deep: false
  variants: true
```

该动作只获取素材相关数据，不执行车控。正常最多 5 个只读请求，每步间隔 3 秒；参数对比、素材包任一步出现风控便停止。报告保存在：

```text
/config/leapmotor-assets/car3d-diag/car3d_diag_*.json
```

发送最新 JSON 报告和车型/年款/配置说明即可。报告只保留素材 key 的长度和少量前缀，车型参数采用白名单，不要求账号、密码、VIN、会话文件或整个 HA 配置目录。转发前仍应检查报告文字。

如果浅探显示包不是 ZIP，或者下载成功但包里缺模型，再按排查者建议单次使用 `deep: true`。它会下载完整素材（通常约 15 MB）、记录目录；非 ZIP 的原始响应另存为 `.bin`。原始响应没有保证脱敏，先发送 JSON；不要直接公开 `.bin`。

出现限流、频繁操作或风控提示后停止，不要重复调用。模型正常时不必运行探针。

## 车窗状态的验证

优先使用具名的四窗百分比属性。四路枚举信号 `1693～1696` 的逐窗顺序尚未验证，本版本只在四位同开或同关时用作统一回显。只有枚举开关值时，3D 只能表现开/关，不能证明实际开度是微开、半开还是全开。

要确认逐窗映射：车主自行选择安全的驻车条件，用车内按键一次只改变一扇窗，待 HA 状态更新后导出诊断，注明操作的是哪扇窗以及开/关方向；每次先恢复原状再测下一扇。无需提供定位、账号信息，也无需允许远程操控车辆。确认映射前不把混合枚举状态猜成左右位置。

## 重复加载与主题

普通车况刷新和重复应用相同卡片配置会复用现有 3D 画布。整页刷新仍需重新初始化 WebGL，但模型、贴图与查看器资源允许浏览器缓存；更新包装页时使用版本化 URL。初始化完成前隐藏画布，背景按所选主题铺底，避免深色模式白屏闪烁。

加载优化会在本地生成查看器与 FBX 解析器的 gzip 副本，并提前请求本车已经存在的模型文件，让模型下载与查看器初始化重叠。B05 普通版与 Ultra 分别使用自己的资源目录；未知别名继续由官方查看器选择。压缩文件在源文件变化时重建，生成失败则使用原文件，不重新下载云端素材，也不改变模型和材质。

包装页的 `first`、`full`、`ready` 回执及 `probe.loadTimes` 分别记录首帧、完整模型、最终显示耗时。文件缓存只能减少传输；手机上的模型解析和 WebGL 初始化仍需执行，因此排查慢加载时应区分首次访问、缓存访问和普通车况刷新。

自定义车漆使用实时预览；调色期间保持原画布高度和取景，确认后保存到本机，返回则恢复原色。
